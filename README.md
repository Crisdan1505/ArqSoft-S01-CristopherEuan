# Catalogo
Durante el desarrollo de este proyecto se ha creado un catalogo de Videojuegos, el cual se encuentra en la carpeta "catalogo" y contiene los siguientes archivos:
La pagina principal es la parte del inicio donde se puede encontrar el nombre del creador del proyecto.
- index.html: Es la pagina principal del catalogo, donde se muestra el nombre del creador del proyecto.

En el apartado de catalogo podemos encontrar los siguientes archivos:
Encontraremos una lista de videojuegos con el nombre del juego, fecha de lanzamiento , genero y una breve descripcion del juego.
- catalogo.html: Es la pagina donde se muestra el catalogo de videojuegos, con su nombre, fecha de lanzamiento, genero y una breve descripcion del juego.

Y por en el apartado contamos con la parte de politica de privacidad, donde se muestra la politica de privacidad del catalogo.
En este caso no podremos visualizar la politica de privacidad, ya que no se ha creado un archivo para ello, pero se puede crear un archivo llamado "politica.html" y agregar la politica de privacidad del catalogo.
